# F1 Data Platform

A production-style data engineering platform built using real Formula 1 data.

## Objective

Build an end-to-end Formula 1 data platform that ingests race data,
processes it using modern data engineering technologies, and produces
analytics-ready datasets.

## Data Source

OpenF1 API

https://openf1.org/

## Planned Architecture

OpenF1 API
    ↓
Python Ingestion
    ↓
Raw Data
    ↓
Databricks
    ↓
Bronze
    ↓
Silver
    ↓
Gold
    ↓
Analytics
